## 🚀 Featured Project — YIELD

### Original Roblox Superhuman Action RPG

**YIELD** is an independently designed and developed open-world superhuman action RPG built in **Roblox Studio and Luau**.

The project combines game development with software architecture concepts including:

- Server-authoritative combat
- Client/server separation
- Request validation
- Modular Luau architecture
- State management
- Semantic input systems
- Momentum-driven combat
- Animation pipelines
- Authoritative contact timing
- Movement and combat integration
- Multiplayer-conscious design
- Iterative testing and debugging

YIELD's original power system, **IMPULSE**, is designed around player-created superhuman identities rather than predefined characters.
